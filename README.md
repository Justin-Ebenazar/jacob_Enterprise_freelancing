<h1>Service Sphere</h1> ⚒️🛠️

Service Sphere is a comprehensive management system developed for a company to efficiently manage their product details, daily processes, and financial operations.

<h1>Features</h1> 🆕
- Product Management: Manage product details, updates, and inventory.
- Financial Support: Handle financial transactions, billing, and calculations.
- Stock Management: Track and manage product stock levels.
- Bill Calculator: Calculate bills and generate invoices.

<h1>Technologies Used</h1> ⚙️
- Backend: Python, Flask
- Frontend: HTML, CSS
- Database: SQL
- Additional Tools: Jinja Code
